# Perfumería Beltrán

Sitio web moderno y responsive para la presentación y comercialización de perfumes de **Perfumería Beltrán**.

## Descripción

Proyecto desarrollado con **HTML5, CSS3 y JavaScript**, con una interfaz elegante y profesional.

La página permite mostrar el catálogo de perfumes, buscar productos, filtrarlos por categoría y contactar directamente al vendedor mediante WhatsApp.

## Características

- Diseño moderno y elegante.
- Diseño responsive para computadoras, tablets y teléfonos móviles.
- Catálogo de perfumes.
- Buscador de productos.
- Filtros por categoría: Hombre, Mujer y Unisex.
- Contador de resultados.
- Mensaje cuando no se encuentran productos.
- Botones de compra mediante WhatsApp.
- Botón flotante de WhatsApp.
- Navegación responsive.
- Animaciones y efectos visuales suaves.
- Imágenes con presentación proporcional.
- Fondo visual premium para la sección de productos.
- Soporte para reducción de animaciones.
- Año del copyright actualizado automáticamente mediante JavaScript.

## Tecnologías utilizadas

- **HTML5** — estructura del sitio.
- **CSS3** — diseño, responsive, animaciones y efectos visuales.
- **JavaScript** — buscador, filtros, navegación y funcionalidades dinámicas.
- **Google Fonts** — tipografías utilizadas.
- **WhatsApp** — contacto directo para consultas y compras.

## Funcionamiento

### Buscador
Permite buscar rápidamente perfumes por nombre.

### Filtros
El catálogo puede filtrarse por categoría para mostrar perfumes de Hombre, Mujer, Unisex o todos.

### WhatsApp
Cada producto dispone de un botón para iniciar una conversación mediante WhatsApp y consultar sobre el producto.

## Instalación

No se requiere ningún servidor para ejecutar el proyecto localmente.

1. Descarga o clona el repositorio.
2. Abre la carpeta del proyecto.
3. Ejecuta `index.html` en un navegador web.

## Publicación en GitHub Pages

1. Crea o utiliza un repositorio en GitHub.
2. Sube `index.html`, `style.css`, `script.js` y la carpeta `imagenes`.
3. Entra a **Settings → Pages**.
4. Selecciona la rama principal, normalmente `main`.
5. Selecciona `/ (root)`.
6. Guarda los cambios.
7. GitHub generará la dirección pública del sitio.

## Personalización

- Productos y contenido → `index.html`
- Colores y estilos → `style.css`
- Funcionalidades → `script.js`
- Fotografías → carpeta `imagenes`
